HOW IT WORKS

이렇게 진행됩니다

단계별 커리큘럼과 꾸준한 관리로 끝까지 완주할 수 있도록 함께합니다.

01

단계별 커리큘럼 상담

학생의 학년과 목표에 맞춰 자바스크립트·파이썬 트랙과 시작 레벨을 함께 정합니다.

02

1:1 화상 수업

전문 선생님과 화면을 공유하며 실시간으로 코드를 작성하고 결과를 함께 확인합니다.

03

끝까지 완주하는 관리

지속적인 진도 확인과 피드백으로 중도에 흐지부지되지 않도록 꾸준히 관리합니다.

TRACK 01 · JAVASCRIPT

자바스크립트로 앱 창작하기

프로그래밍 기초 문법부터 시작해 자바스크립트를 활용한 웹·게임·앱 제작까지 단계별로 익힙니다.

배우는 언어자바스크립트(JavaScript)
수업 방식1:1 화상 수업만 진행 (방문 없음)
활용 분야웹, 게임, 앱 등
Lv1

게임 만들기 첫걸음

변수·조건문 등 기초 문법으로 간단한 게임을 만들어봅니다.

Lv2

캐릭터 움직이기

반복문과 이벤트 처리로 캐릭터를 조작하는 게임을 완성합니다.

Lv3

미니게임 완성하기

함수를 활용해 점수·목숨 등 게임 규칙을 갖춘 미니게임을 만듭니다.

Lv4

인터랙티브 웹앱 만들기

사용자 입력에 반응하는 인터랙티브 웹 페이지·앱을 제작합니다.

Lv5

나만의 프로젝트

배운 내용을 종합해 스스로 기획한 나만의 게임·앱 프로젝트를 완성합니다.

TRACK 02 · PYTHON

파이썬으로 데이터 분석하기

파이썬 기초 문법을 익히고, 실제 데이터를 다루고 시각화하는 과정까지 진행합니다.

배우는 언어파이썬(Python)
수업 방식1:1 화상 수업만 진행 (방문 없음)
활용 분야데이터 분석, AI, 웹 등
Lv1

파이썬 기초 다지기

변수, 자료형, 조건문·반복문 등 파이썬 기본 문법을 익힙니다.

Lv2

데이터 다루기

리스트·딕셔너리 등으로 실제 데이터를 정리하고 가공하는 법을 배웁니다.

Lv3

데이터 시각화·분석 프로젝트

배운 내용을 종합해 데이터를 그래프로 시각화하고 분석하는 프로젝트를 완성합니다.

FAQ

자주 묻는 질문

코딩을 처음 배우는데도 괜찮나요? 사전 지식이 필요한가요?+

네, 처음 배우는 학생도 충분히 시작할 수 있습니다. 기초 개념부터 차근차근 안내하며, 학생의 이해 속도에 맞춰 레벨을 조정해드립니다.

몇 학년부터 수업이 가능한가요?+

초등학생부터 중·고등학생까지 폭넓게 가능합니다. 2025년부터 중학교, 2026년부터 초등학교 정보(코딩) 수업이 단계적으로 필수화되는 만큼, 미리 기초를 다져두고 싶은 학생들도 많이 찾아주십니다.

자바스크립트반과 파이썬반 중 어떤 걸 선택해야 하나요?+

게임이나 앱처럼 눈에 보이는 결과물을 직접 만들어보고 싶다면 자바스크립트반을, 데이터를 다루고 분석하는 데 흥미가 있거나 AI 분야에 관심이 있다면 파이썬반을 추천드립니다. 상담 시 학생의 관심사에 맞춰 안내해드립니다.

수업은 어떻게 진행되나요? 방문 수업도 가능한가요?+

코딩미는 1:1 화상 수업만 진행하며, 방문·대면 수업은 제공하지 않습니다. 화면 공유를 통해 실시간으로 코드를 함께 작성하고 확인하는 방식으로, 전국 어디서나 동일하게 수업받을 수 있습니다. 원활한 실습을 위해 노트북이나 데스크톱 컴퓨터가 필요하며, 정확한 사양은 상담 시 안내해드립니다.

레벨은 어떻게 올라가나요? 이전 레벨을 다 끝내야 다음으로 넘어가나요?+

레벨별로 만들어보는 결과물이 정해져 있어, 이전 단계를 충분히 이해하고 완성한 뒤 다음 레벨로 넘어갑니다. 이해가 느린 부분은 반복 학습으로 다지고, 빠른 학생은 진도를 유연하게 조정합니다.

무료 시범수업은 어떻게 신청하나요?+

전화 또는 카카오톡으로 신청하시면 간단한 상담 후 무료 시범수업 일정을 잡아드립니다. 시범수업에서 실제 수업 방식을 미리 체험해보실 수 있습니다.

학교 진도나 코딩 대회 준비도 도와주시나요?+

네, 학교 정보 교과 진도에 맞춘 보충 학습은 물론, 코딩 관련 대회나 특기 활동을 준비 중인 학생도 목표에 맞춰 커리큘럼을 조정해드립니다.
